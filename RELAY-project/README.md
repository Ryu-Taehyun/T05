# RELAY — 이어서 하는 작업

index.html을 브라우저에서 열면 바로 사용할 수 있습니다. 초기 작업 3개는 시연용입니다.

- 새 작업: 제목과 메모를 입력하고 추가합니다.
- 카드 하단에서 할 일 / 진행 중 / 완료를 선택합니다.
- 오른쪽에 목표, 다음 행동, 주의할 점을 적습니다.
- 다른 환경으로 옮길 때 JSON 인수인계 파일을 내보내고, 새 환경에서 같은 HTML을 열어 불러옵니다.
- 기존 보드를 교체하기 전 현재 파일을 내보내 보관하세요.

report.html에는 과제 제출용 설명과 검증 집계가 있습니다. HANDOFF.md는 실제로 A가 B에게 넘긴 7항목 문서입니다. B-RESULT.md에는 B가 수행한 검사와 제한이 기록됩니다.

외부 라이브러리나 인터넷 연결은 필요하지 않습니다. 자동 저장은 브라우저와 HTML 파일 위치에 따라 별도로 유지됩니다. 저장을 사용할 수 없을 때도 현재 작업은 JSON으로 보관할 수 있습니다. 파일을 함께 옮기면 보고서 링크도 사용할 수 있습니다.

개발 검증: Node가 설치되어 있으면 이 폴더에서 `node verify.cjs`, `node verify-b.cjs`를 실행합니다. 실제 브라우저 시각 검증은 완료하지 못했으므로 배치와 다운로드 창은 직접 확인이 필요합니다.
